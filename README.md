# ARB Standard Bank

A simple Bank Management System built with React and Vite. This frontend application simulates basic banking operations such as checking account balance, depositing money, withdrawing money, and viewing transaction history.

## Features

* Dashboard with account information and balance summary.
* Deposit money with input validation.
* Withdraw money with validation and minimum balance requirement of ৳500.
* Confirmation before withdrawal.
* Transaction history with deposit and withdrawal records.
* Automatic data persistence using Browser LocalStorage.
* Responsive user interface.
* Navigation using React Router DOM.

## Technologies Used

* React
* Vite
* JavaScript
* React Router DOM
* HTML
* CSS
* Browser LocalStorage

## Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd bank-management
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.

## Production Build

To create a production build, run:

```bash
npm run build
```

## Note

This is a frontend-only educational project. It does not use a backend, database, or perform real banking transactions. Account information and transaction history are stored locally in the user's browser.
